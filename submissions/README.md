# Paper drafts

| directory | what it is |
| --- | --- |
| `wolfram/` | the original paper: LaTeX sources (`ForEric.tex` long version, `shortversion.tex`, `original.tex`), the published figures, and the Mathematica notebook `anc/DatingMarriageModel.nb` that generated them |
| `aamas/` | the AAMAS 2026 port, `marriage.tex`, built with `make`. See `aamas/NOTES.md` |

Figures in `aamas/figures/` come from `results/` via `aamas/sync_figures.sh`;
figures in `wolfram/` are the originals and are not regenerated.
